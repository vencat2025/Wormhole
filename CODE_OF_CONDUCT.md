# Code of Conduct

Be decent to people. Assume the person on the other end is trying.

Specifically: no harassment, no personal attacks, no demeaning comments about
who someone is. Critique the code, the claim, or the measurement — not the
person who wrote it.

Disagreement about technical claims is welcome and expected here. This project
has already published a number that turned out to be wrong; the person who
pushed back was doing it a favour. Bring evidence, and be willing to be shown
evidence back.

If someone's behaviour is a problem, email cvprasad@gmail.com. Reports go to
the maintainer only. As a spare-time project there is no committee behind this,
but reports will be read and acted on, up to blocking someone from the
repository.
